# SimulationJava
2 проект из Java роадмап Сергея жукова. (https://zhukovsd.github.io/java-backend-learning-course/projects/simulation/)

Проект представляет собой пошаговая симуляция 2D мира, населённого травоядными и хищниками. Кроме существ, мир содержит ресурсы (траву), которыми питаются травоядные, и статичные объекты.

2D мир представляет из себя матрицу NxM, каждое существо или объект занимают клетку целиком, нахождение в клетке нескольких объектов/существ - недопустимо.
